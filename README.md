# video-subtitle-render

## 题面

字幕改成自动排版后，中文长句被截断、描边还把字裁掉一半：中文按半角计算，测得宽度只有实际的一半，长句换行整体错位；换行在标点前断开，出现以标点开头的孤字行；行高直接取字号，行距变成 0，多行字幕叠在一起；九宫格锚点只实现了底部居中，上、左、右等八个方向全部落到错误位置；描边外扩时把内框一起放大，文字边缘被裁掉；安全区不判断越界方向，越界元素被反向推回后覆盖相邻元素；阴影不按画布裁剪，画布外坐标直接报错；样式校验不检查行高与字号关系，行间重叠无法拦截；批量排版共用同一份布局缓冲，块与块之间的行框互相串位；未知 align 被静默当成居中，错误配置无法暴露。subsrender/layout.py 是核心，tests/test_layout.py 15个红。要修的是：中文与半角字符分别按全角、半角累计像素宽度；换行不得以标点开头，必要时让标点留在上一行；竖直步长严格使用 line_height；九个锚点都按整块宽高计算 origin；描边只扩大 outer 盒，inner 保持原样；安全区按越界方向做最小平移；阴影按画布边界裁剪且不产生负坐标；validate_style 检查行高小于字号并返回问题；render_batch 为每块新建行框缓冲并保证原子回滚；未知 align 由 validate_style 报告且 layout_block 抛 SubRenderError。

## 运行方式

在仓库根目录执行：

```powershell
python -m pytest tests -q
```

初始状态必须恰好是 `15 failed`，并且没有 collection error、import error 或 syntax error。实现完成后应变为 `15 passed`。所有尺寸单位为像素，比较容差为 0.5 像素。

## 约束

- `tests/test_layout.py` 不可修改；这 15 条测试就是验收标准。
- 只实现 `subsrender/layout.py` 中的 8 个函数，保持现有函数签名和返回结构。
- 仅使用 Python 标准库（`math`）与 pytest，离线运行，不使用随机数。
- 所有几何量以像素为单位，结果按 0.5 像素容差比较。
